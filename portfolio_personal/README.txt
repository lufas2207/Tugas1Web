PORTFOLIO PERSONAL — PETUNJUK

Isi folder:
- index.html : struktur halaman website (HTML5)
- style.css  : desain dan layout website (CSS3)

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder portfolio_personal.
3. Klik dua kali index.html, atau buka menggunakan browser.
4. Untuk mengedit kode, buka folder dengan Visual Studio Code.

YANG PERLU KAMU GANTI
Cari dan ganti teks contoh berikut di index.html:
- "Nama Kamu" / "Nama Lengkap Kamu"
- "Kota Kamu, Indonesia"
- "emailkamu@example.com"
- Nama perguruan tinggi, program studi, dan sekolah
- Isi proyek contoh dengan proyek yang benar-benar kamu buat
- Tautan LinkedIn dan GitHub dengan akun milikmu

CATATAN TUGAS
- Website memakai HTML5 dan CSS murni, tanpa Bootstrap/Tailwind.
- Responsivitas dibuat menggunakan media queries pada style.css.
- Persentase keahlian hanyalah contoh; sesuaikan dengan kemampuan sebenarnya.
- Foto profil belum dipakai; kartu profil memakai inisial "NK" agar mudah diganti.
